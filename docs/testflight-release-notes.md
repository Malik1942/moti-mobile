# Moti V1 TestFlight Release Notes

Moti V1 is an AI-native project timeline manager.

## What's Included

- Natural language capture for work items
- On-device Foundation Model parsing when available
- Rule-based fallback parsing
- Project-based timeline view
- Continuous work period visualization
- Due date and working period editing
- Review flow for unclear captures
- Local-first work data storage

## Known Limitations

- Foundation Models availability depends on device and OS support
- Calendar sync is not included yet
- Notifications are not included yet
- Voice capture may be placeholder if not implemented
